# Журнал решений

Коротко: что решили, когда и почему. Подробности — в соседних документах.

| Дата | Решение | Почему |
|---|---|---|
| 2026-10-16 | Ядро продукта — macOS/iOS CI-проверки. Edge и серверы не делаем | Нагрузка, где утечка и подмена результата не критичны, а падение ноды переживается (`product.md`) |
| 2026-10-16 | Параллельно замеряем MLX в VM | Обучение — возможное второе направление на том же агенте (`bench/mlx/`) |
| 2026-10-16 | Всё на Swift: агент, служба гостя, приложение. Control plane на Vapor | Virtualization.framework и UI нативно на Swift, общие типы протокола |
| 2026-10-16 | Новые Xcode-проекты — в JSON `project.xcproj` | Удобнее читать и ревьюить |
| 2026-10-17 | Минимальные версии: macOS 27 / iOS 27 | Разрешено поднимать, если это помогает |
| 2026-10-17 | Исследуем удалённый симулятор | Потенциально сильная фича, интерактивная сессия лучше ложится на лицензию |
| 2026-10-19 | Образы VM и большие холодные данные — на внешнем SSD `/Volumes/Dev`, горячие кэши сборки — на внутреннем | Скорость USB-SATA ~250 МБ/с |
| 2026-10-19 | Базовый образ — Cirrus `macos-golden-gate-vanilla` + Xcode и рантайм с хоста | Не проходить Setup Assistant руками. Позже — своя сборка (`images/build.sh`) |
| 2026-10-21 | Первые пользователи — свои и команда (private pool). Треки CI и симулятор параллельно | Снимает доверие и лицензионные вопросы |
| 2026-10-21 | Связь клиента с хостом — WebRTC (P2P + TURN) | Видео в реальном времени, браузер, обход NAT из коробки (`networking.md`) |
| 2026-10-21 | Сеть гостя — собственный NAT в агенте, только интернет | Без root и pf, гость не видит LAN владельца |
| 2026-10-21 | Основной клиент симулятора — браузер на TypeScript | Многие клиенты на Linux и Windows. Mac Viewer остаётся для замеров |
| 2026-10-21 | Нативная обёртка клиента — потом, кандидат Wails 3 | Поверх того же веб-клиента. На Linux, возможно, WebRTC через pion |
| 2026-10-21 | Работа идёт в параллельных сессиях A–D по контрактам (`contracts.md`) | Каждая папка — у одного владельца, в `main` сливает координатор |
| 2026-10-21 | WebRTC на стороне мака — libdatachannel | Лёгкий, умеет передавать готовый H.264 без перекодирования |
| 2026-10-21 | Мини-прод без аккаунтов: один общий токен | Быстрее до живого стенда, инвайты в коде уже есть |
| 2026-10-21 | Control plane для мини-прода на Vapor, потом перепись на Go | Go: pion/turn, один бинарь, общий язык с Wails. `deploy/` и JSON-фикстуры переиспользуем |
| 2026-10-21 | Режим видео (дорожка или канал данных) не выбираем по браузеру. По умолчанию дорожка | Решим по замерам в реальных условиях |
| 2026-10-21 | Сначала локальный прогон всего стека в Docker, потом деплой на сервер | Сквозной прогон прошёл: браузер на втором маке → симулятор в VM, соединение прямое |
| 2026-10-21 | Подпись Developer ID и нотаризация — в последнюю очередь | До этого подпись ad-hoc |
| 2026-10-21 | Перевод control plane на Go начинаем сразу (сессия E), TURN встраиваем через pion | Сервер пока маленький, фикстуры — готовая приёмка. Протокол от языка не зависит, VPN-экосистема на Go (`networking.md`) |
| 2026-10-21 | Go-версия control plane сразу с аккаунтами: вход через GitHub OAuth, команды с пулами маков, Postgres. Лимиты, аудит, метрики — в TODO | Нормальный вход и изоляция команд нужны до внешних пользователей. Контракт — `Teams.swift` |
