# Maccheri Viewer

Приложение macOS для подключения к `simstream`: показывает экран удалённого симулятора iOS, мышь
работает как палец. Проект в JSON-формате `MaccheriViewer.xcodeproj/project.xcproj` (Xcode 27.2+).
Использует `SimStreamClient` из `../simstream`.

## Сборка

```sh
viewer/scripts/package.sh    # → viewer/build/MaccheriViewer.zip (universal, подпись ad-hoc)
```

## Запуск на другом маке

1. Скопировать `MaccheriViewer.zip` любым способом (AirDrop, scp, флешка), распаковать и положить
   `MaccheriViewer.app` куда угодно. Нужна macOS 15 или новее.
2. Подпись ad-hoc, поэтому Gatekeeper откажет: «Apple не может проверить…». Варианты:
   - в Терминале: `xattr -dr com.apple.quarantine /path/to/MaccheriViewer.app`, потом открыть как обычно;
   - либо попытаться открыть, затем System Settings → Privacy & Security → «Open Anyway»
     (на старых macOS работает ПКМ → «Открыть»).
3. При первом подключении macOS спросит разрешение на доступ к локальной сети. Нужно разрешить,
   иначе подключение будет молча висеть. Если запрос пропустили:
   System Settings → Privacy & Security → Local Network → Maccheri Viewer.
4. Ввести `Mac-mini-Artem.local:7300` и нажать Connect.

## Управление и оверлей

- Нажатие, перетаскивание и отпускание мыши превращаются в касание, свайп и отпускание.
  Координаты нормируются к экрану устройства. Окно держит его пропорции.
- Оверлей: fps и Мбит/с за последние 0,5 с (в простое 0, так и должно быть: кадры приходят только
  при изменениях), RTT до сервера, задержка клик → кадр (последняя, p50, p95 по 200 последним
  кликам), серверная часть и время декодирования.
- Задержка считается от нажатия кнопки мыши до декодирования кадра, в котором видно это нажатие.
  Отрисовка на экране добавляет ещё от 0 до 16 мс, до следующего vsync.

Для проверки без мыши:
`open MaccheriViewer.app --args -address host:7300 -autoconnect YES -benchTaps 60`.
Приложение само кликнет в центр экрана 60 раз, а результат появится в оверлее. В симуляторе должен быть
открыт TapProbe.
